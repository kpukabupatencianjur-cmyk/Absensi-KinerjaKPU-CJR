=====================================================================
 PANDUAN APLIKASI ABSENSI PEGAWAI - SEKRETARIAT KPU KABUPATEN CIANJUR
 (bisa dipasang di HP Android, iPhone, dan PC/Laptop)
=====================================================================

Aplikasi ini adalah "pembungkus" untuk sistem absensi Apps Script Anda.
Data tetap di Google Sheets seperti biasa. Aplikasi hanya membuat sistem
bisa dibuka dari ikon di layar HP/PC, layar penuh, tanpa copy-paste link.

---------------------------------------------------------------------
 LANGKAH 1 - Perbarui Apps Script (sekali saja, oleh admin)
---------------------------------------------------------------------
1. Ganti isi Code.gs dengan code.gs terbaru (IZINKAN_EMBED_IFRAME sudah true).
2. Terapkan -> Kelola deployment -> klik ikon pensil (Edit)
   -> Versi: "Versi baru" -> Terapkan.
   PENTING: jangan pilih "Deployment baru", karena URL-nya akan berubah.
3. Salin "URL aplikasi web" (berakhiran /exec).
   Pastikan "Siapa yang memiliki akses" = "Siapa saja".

---------------------------------------------------------------------
 LANGKAH 2 - Isi URL di config.js
---------------------------------------------------------------------
Buka file config.js dengan Notepad, lalu ganti:
   https://script.google.com/macros/s/GANTI_DENGAN_ID_DEPLOYMENT/exec
dengan URL /exec dari Langkah 1. Simpan.

---------------------------------------------------------------------
 LANGKAH 3 - Unggah ke GitHub Pages (gratis, sekali saja)
---------------------------------------------------------------------
Aplikasi harus tinggal di alamat https agar bisa dipasang.
1. Buat akun di https://github.com (gratis), lalu login.
2. Klik "+" (kanan atas) -> "New repository".
   - Repository name: absensi-kpu
   - Pilih "Public" -> klik "Create repository".
3. Klik tautan "uploading an existing file".
   Seret SEMUA isi folder aplikasi-absensi (index.html, config.js,
   manifest.webmanifest, sw.js, dan folder "ikon") ke halaman itu.
   Klik "Commit changes".
4. Buka tab "Settings" -> menu "Pages".
   - Source: "Deploy from a branch"
   - Branch: "main", folder "/ (root)" -> klik "Save".
5. Tunggu 1-2 menit, muat ulang halaman Pages. Alamat aplikasi muncul, misalnya:
   https://NAMA-AKUN-ANDA.github.io/absensi-kpu/
   Inilah link yang dibagikan ke pegawai (cukup SATU KALI).

---------------------------------------------------------------------
 LANGKAH 4 - Pegawai memasang aplikasi (sekali saja per perangkat)
---------------------------------------------------------------------
HP ANDROID (Chrome):
   Buka link -> menu titik tiga (⋮) -> "Instal aplikasi"
   atau "Tambahkan ke layar utama" -> Instal.
IPHONE (Safari):
   Buka link -> tombol Bagikan (kotak dengan panah ke atas)
   -> "Tambahkan ke Layar Utama" -> Tambah.
PC / LAPTOP (Chrome atau Edge):
   Buka link -> klik ikon "Instal" di ujung kanan kolom alamat
   (atau menu ⋮ -> "Transmisikan, simpan, dan bagikan" -> "Instal halaman sebagai aplikasi")
   -> Instal. Aplikasi muncul di Start Menu / Desktop.

Setelah itu pegawai cukup klik ikon "Absensi KPU" setiap mau absen.

---------------------------------------------------------------------
 CATATAN
---------------------------------------------------------------------
- Perubahan sistem nanti (Code.gs / Index) TIDAK perlu pasang ulang aplikasi,
  asalkan selalu memakai "Kelola deployment -> Edit -> Versi baru".
- Jika di HP tertentu GPS atau unggah surat sakit tidak berfungsi di dalam
  aplikasi, ubah MODE di config.js dari 'tanam' menjadi 'langsung', lalu
  unggah ulang config.js ke GitHub. Aplikasi akan membuka sistem langsung
  di halaman Google (tetap dari ikon yang sama).
- Login tetap berakhir otomatis setelah 15 menit tidak aktif, sama seperti di browser.
- Untuk akun Google pribadi (bukan Google Workspace), Google selalu
  menampilkan bilah keterangan "dibuat oleh pengguna Google Apps Script"
  di atas halaman. Ini bawaan Google dan tidak bisa dihilangkan.
